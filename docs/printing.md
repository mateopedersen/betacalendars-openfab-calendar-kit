# Printing

Each dated month is supplied as a one-page PDF for A4 and US Letter, portrait and landscape, with Monday-first and Sunday-first variants. Print at **actual size / 100%** if you need dimensions to match; use fit-to-page only when scaling is acceptable. Margins are built into the page. The blank references are genuinely undated and include 5×7 and 6×7 grids.
