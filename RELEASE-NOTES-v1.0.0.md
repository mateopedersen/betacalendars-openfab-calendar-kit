# BetaCalendars OpenFab Calendar Kit v1.0.0

First digital design release of the parametric calendar fabrication kit.

Includes source generator; monthly 2027 Monday-first and Sunday-first SVG files; A4 and US Letter PDFs in portrait and landscape; 5×7 and 6×7 blank templates; laser stencil, board and token vectors; millimeter DXF; documentation; and open licenses. All calendar layouts are generated from Gregorian date calculations. Files are digitally validated; no physical fabrication test or machine compatibility claim is included.
