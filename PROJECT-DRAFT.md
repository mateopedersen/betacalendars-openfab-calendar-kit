# Hosted project draft

**Title:** BetaCalendars OpenFab Calendar Kit  
**Summary:** Parametric laser-cut, pen-plotter and printable calendar fabrication system.

An open digital-fabrication toolkit for creating reusable calendar stencils, plotter-drawn month grids and printable planning sheets from deterministic Gregorian calendar geometry. The project includes a 190 × 260 mm 7×6 stencil, a planning board, date/month/weekday token vectors, 2027 monthly SVG fixtures, blank grids, a millimeter DXF, and A4/US Letter PDFs. Designed for adaptable workflows in maker spaces, classrooms, workshops and personal planning. Digital validation is documented; no physical prototype is claimed.

**Website:** https://www.betacalendars.com/
